ストーリー全 18 件の "As a" に登場する利用者像を整理する。プロダクトはペルソナ P1 (主) を中心に設計されているが、リスク R12 対策のため P2 (誤利用者) を **想定外ユーザー** として明示し、設計で誤利用を防ぐ責務を負う。

## P1: 疲弊した 20 代社会人 (主ペルソナ / 設計の中心)

### 属性
| 観点 | 内容 |
|---|---|
| 年齢層 | 20 代 |
| 職業 | 会社員 / フリーランス / 非正規含む。仕事に疲弊しがち |
| 行動傾向 | 帰宅後にソファ/ベッドで動けなくなる |
| 心理状態 | 風呂をサボることへの罪悪感、自己肯定感の揺らぎ |
| 嗜好 | ユーモアと自虐が好き、「ダメな自分」をネタにできる感性 |
| 利用シーン | 帰宅後 21〜25 時、ソファ/ベッドで片手操作 |
| 利用頻度 | ほぼ毎日 (リピート前提) |

### モチベーション (Why)
- 罪悪感を薄めたい (NFR-CON-01「真剣に責めない」)
- 「自分はダメだ」を笑いに転化したい (`requirements.md` Differentiators: ダメ自慢 × 過激称号 / FR-10)
- 健康への配慮はゼロではない (US-2.4 トーンシフトの受容)

### ペインポイント (Pain)
- 既存の健康促進アプリの「ちゃんとしなさい」プレッシャーが逆に動けなくする
- ソファから動けない時間に「動かなくていい」と肯定してくれる存在がいない
- 真面目な記録アプリは、サボり履歴を見ると落ち込む配色や演出が多い (US-3.2 で中立配色採用の理由)

### このプロダクトでの主要ストーリー (P1 が直接的にユーザーである **21 件 / Revision 2 で 18→21**)
全 21 ストーリーがこのペルソナを対象とする。特に重点:
- **コア体験**: US-1.1, US-1.3, US-1.5, **US-1.6 (カレンダー反映 / Revision 2)**, US-2.1, US-2.2, US-2.4, US-3.1, US-3.2
- **継続性**: US-4.1, US-4.2 (称号によるリピート動機)
- **トーン保護**: US-2.4, US-5.5 (健康配慮ポリシーの実装)
- **ダラけ感の体験**: US-5.6 (UI 演出)
- **決意倒れ体験のネタ化 (Revision 2)**: **US-3.3 (達成確認通知)** / 罪悪感を笑いに転化する補助
- **判断材料の補完 (Revision 2)**: **US-5.7 (翌日予定ホーム画面ミニ表示)** / 「明日早起き」を決意の材料に

## P2: 真剣な健康相談を求めて誤って起動した利用者 (想定外ペルソナ / R12 対策)

### 属性
| 観点 | 内容 |
|---|---|
| 想定 | アプリ名や説明から「健康相談アプリ」と誤解した利用者 |
| 心理状態 | 真剣に風呂・健康についてアドバイスを求めている |
| 期待値 | 医療・看護・公衆衛生レベルの真面目な指導 |

### このペルソナへの責務 (設計での扱い)
このペルソナは **本プロダクトのターゲットではない** が、誤って利用してしまった場合に害を与えないことが NFR-CON-04 とリスク R12 (重要度: 中) で要求されている。

#### 関連ストーリー (P2 を対象とした「離脱誘導」)
- **US-5.5【M】★ コンセプト明示オンボーディング**: 「これは『人をダメにする』ためのおふざけアプリです / 真剣な健康相談には使わないでください」を明示し、同意ボタンタップを必須にする
- **US-5.1【M】 オンボーディング**: ジャッジと悪魔のキャラクター紹介でトーンを伝える
- **US-5.3【M】 設定画面**: 設定画面から US-5.5 のコンセプト説明を再表示可能

### 設計上の制約
- LLM が真剣な医療アドバイスを返すことを禁止 (US-2.1 の AC「責めない」+ システムプロンプトで誘導)
- 称号は事前リスト化のみ (US-4.2 / リスク R13) で、不快な体験を防ぐ
- 真面目な相談を期待した利用者がアプリを離脱できる経路を確保 (US-5.5 の同意フロー)

## 補足: ペルソナ設計の方針

- **シンプル構成 (1 主 + 1 想定外)**: ハッカソンの規模感では複数ペルソナを設計しない。コア体験を P1 に集中
- **想定外ペルソナの明示**: リスク R12 を要件・ストーリーに反映するため、P2 を想定外として明示する
- **C 級 (Could) ペルソナは設けない**: 共有・SNS シェア機能などはスコープ外 (`requirements.md` Scope Exclusions)
